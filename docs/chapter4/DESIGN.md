## 闭环与三个候选改进

公开任务观测、角色、阶段、历史命令与参考命令组成 Actor 输入；公开转移更新集合；策略提案通过共同保护接口，进入延迟/迟滞/噪声和原生物理积分；训练 Critic 可读取真实 context，部署 Actor 和在线估计器不能读取。任务奖励、成功/碰撞/终止、目标/障碍和可靠通信协议沿用父版本，新增物理参数只作用于本次创建的 CH4 环境实例。

**A：共享流场与个体响应的经验粒子集合。** 两个流场幅度参数在四个车辆间共享；其余七个参数保留每车独立值。每个粒子代表一个共享物理世界，公共场在不同位置的值可因空间函数不同而不同。公开有效转移给出逐车速度残差，共享模式联合检验相同场参数；不会把四个车辆的个体阻力区间直接求交。输出是被接受粒子的逐维凸包加声明 padding，并保留有效性、支持量、原因。盒状外包络会丢失参数关联，不等于精确可行集。

**B：延迟、迟滞与命令历史一致。** 保存实际送往执行器的命令。每个粒子持有整数延迟假设和自己演化的迟滞状态，按候选执行器响应预测下一速度；有限历史窗口内残差必须满足经验阈值。冻结、速度可能裁剪、墙边或碰撞等转移依据公开量排除出辨识条件，但原始轨迹和任务统计仍保留。粒子不足即返回无效全先验，重采参数与未知执行器状态，并经过记忆暖机；不因想展示收缩而把空集合包装为可信区间。当前规则不是带变化界的严格集合辨识证明。

**C：支持门槛下的联合低回报尾部效用。** Critic 在事实转移上学习 `Q(public_observations, joint_proposal, true_context)`；下一 context 来自实际下一转移，不能将一条转移随意换标签复制。Actor 更新时从当时公开集合坐标均匀抽样联合参数，整数延迟离散均匀，四车共享同一流场；默认 `N=16`、`alpha=0.25`，取最低 `floor(alpha*N)=4` 个双 Critic 最小值的均值。声明最低尾部样本为 2。

尾部查询要求集合有效，并要求每个查询在归一化 30D 参数空间的 RMS 半径 0.45 内至少有 8 个不同事实 context；重复同一物理 context 不增加独立支持。该行所有查询均满足才用尾部，否则回退到事实 context 的普通 SAC 效用。日志记录支持及回退行数。该门槛只约束参数邻域，不证明状态/动作联合支持或 Critic 反事实正确性。阶段进入 Actor/Critic 条件，原奖励与任务完成规则不变；没有额外分位数 Critic、因果图或对抗生成器。

## 独立 SAC 与监督参照

四个 Actor 各自采用 61D 输入、两层 MLP、高斯均值/标准差和 tanh 映射；以公开名义参考的 `atanh` 平移高斯均值，再对最终动作精确计算 tanh 变量变换密度。没有先采动作再把参考直接加到输出上。Critic 输入为 `4×61 + 12 + 30 = 286D`，输出标量团队 Q；双网络和 target 网络独立于第三章模型。温度自动更新，目标熵按当前活动车辆数设定。原任务超时属于继承的终止；单独 collector truncation 不屏蔽 bootstrap。

`EnsembleIdentifier` 是监督学习参照：公开历史转移特征、角色、公开先验条件下预测归一化真实参数，使用训练期真值 MSE。默认 4 个成员；均值±标准差只是启发式范围，未校准成置信区间。`sirsa_naive` 使用每车独立成员；`b_off` 使用角色条件共享成员。为避免未经证据的递归塌缩，当前每次从**完整公开先验**估计窗口，保持与监督训练先验输入一致；未训练 identifier 返回无效先验，权重评估恢复 identifier 更新次数。这与原 SIRSA 的递归先验路径存在明确差异。

## 方法身份

| 方法 | 集合/输入 | 学习目标及用途 |
| --- | --- | --- |
| `nominal` | 无集合特征，固定公开名义控制 | 无学习，OLD/D2 参考；运行协议仍可选择受扰 |
| `uniform_dr` | 固定先验，集合特征清零 | 同权限普通 SAC，均匀域随机化 |
| `point` | 独立监督 ensemble，宽度清零 | 普通 SAC，点条件参照 |
| `fixed_set` | 固定先验区间 | 有门槛的尾部 SAC，诊断在线集合价值 |
| `sirsa_naive` | 独立监督 ensemble 区间 | SIRSA 思想的朴素多智能体适配，非原方法复现 |
| `full` | A+B 共享粒子集合 | C 尾部效用，完整候选 |
| `a_off` | 各车独立粒子检验 | 去共享对照；联合查询的共享场取各车区间的并包络 |
| `b_off` | 共享监督 ensemble | 移除物理延迟/迟滞候选传播的参照，并非保持估计器其余细节完全相同 |
| `c_off` | 同 full 集合、输入、查询与支持门槛 | `risk_alpha=1`，使用所有集合查询的平均价值，单独移除低尾偏好 |
| `phase_off` | 同 full，阶段特征置零 | 单独检验阶段输入；阶段任务规则不改 |
| `fixed_width` | 估计中心，输入宽度固定为归一化全宽 | 风险查询回完整先验，不能仅解释成单一输入字段干预 |

所有学习方法使用各自新模型、新回放和独立重训。`c_off` 保持与 full 相同的场景查询和支持条件，仅将训练效用的尾部比例设为 1；`phase_off` 另行移除阶段特征。结果统计中的低回报尾部仍采用配置声明的报告 alpha，不因 `c_off` 的训练效用平均化而取消。`b_off` 改变估计器类别，`fixed_width` 同时改变风险查询域，后续解释因果贡献时必须说明这些差异。点估计参照也同时采用普通风险目标；不足以单独证明宽度输入的净贡献。

## 物理量与协议

| 参数 | 名义值 | 当前公开先验 | 实际含义 |
| --- | --- | --- | --- |
| `flow_gain` | 0.18 | [0.15, 0.28] | 共享水平空间流场幅度 |
| `flow_z_gain` | 0 | [-0.025, 0.025] | 共享垂向增量 |
| `drag_scale` | 1 | [0.85, 1.2] | 各车阻力缩放 |
| `buoyancy_bias_delta` | 0 | [-0.02, 0.025] | 各车原浮力项增量 |
| `a_max_scale` | 1 | [0.85, 1.1] | 原加速度尺度乘一次，代表有效控制能力 |
| `v_max_scale` | 1 | [0.9, 1.05] | 各车速度限制缩放 |
| `actuator_lag` | 0 | [0, 0.25] | `filtered_t = lag*filtered_(t-1)+(1-lag)*delivered_t` |
| `action_delay_steps` | 0 | {0, 1, 2} | 整数物理步命令延迟 |
| `action_noise_std` | 0 | [0, 0.02] | 迟滞后归一化命令上的高斯噪声尺度，随后裁剪 |

单位沿用父环境：空间/速度/加速度与 `dt` 采用其仿真单位，未作真实海试标定。`a_max_scale` 作用一次，不再乘第二次命令；`v_max_scale` 是限速参数，不能直接称作真实推进器故障。

`nominal` 关闭新增扰动并保留原基础流场，走原积分路径且不额外抽随机数；`episode` 每回合固定采样；`piecewise` 按预定义物理步改变参数；`drift` 对连续参数施加有界每步变化，整数延迟保持。参数流与噪声流独立，以场景种子绑定，便于跨方法成对比较。执行器新回合零队列、零迟滞复位。

`in_domain` 的真实采样域等于公开先验。`heldout_flow` 将水平流场幅度移到 [0.28, 0.36]；`heldout_response` 改变阻力、能力、限速、迟滞，并采用 3 步延迟。两者保持 Actor/估计器原先验，仅供评估。其边界部分与训练域相接，不能概括为每个参数点均严格不相交；这些情形检验失配而不是证明全域泛化，漏覆盖应如实记录。

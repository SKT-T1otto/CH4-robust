# v2实验设计与评审边界

状态：待实现、校准和手动验收。下列比较与门槛是拟议协议，不能写成已完成实验。

## 1. 共同条件与方法身份

主域为21维：共享水平流场系数g一维，加四艇各自的阻力、有效控制能力、净垂向偏置、迟滞和整数延迟五维。固定g_z=0、vmax比例=1；净垂向偏置不再与浮力、竖直流分别辨识。噪声已知固定：0用于主机制检查，0.01用于单列鲁棒组，不混合统计。保留原奖励、任务与合法通信权限；各组Actor仅访问同一合法观测、阶段、命令历史及指定估计摘要，真实参数仅供隔离诊断。

分开记录原SIRSA官方任务复现、v1 sirsa_naive适配、v2朴素ensemble参照。三者不能互称复现，也不能把版本修正收益算作A/B贡献。主对照为冻结D2、UDR、点估计条件策略、固定集合策略、v2朴素集合参照和A+B方法；SAC后端、训练预算、保护器及风险查询权限一致。原SIRSA复现单独制表，不参加AUV任务排名。

## 2. 核心2×2因子实验

统一联合候选表示、物理知识、初始先验、候选数、场景数、压缩方式和重置规则，只改变共享与辨识时序：

| 组别 | S：共享更新 | T：辨识历史传播 |
|---|---|---|
| S0T0 | 独立 | 零时序 |
| S1T0 | 共享 | 零时序 |
| S0T1 | 独立 | 候选延迟/迟滞对齐 |
| S1T1 | 共享 | 候选延迟/迟滞对齐，即A+B |

S0保留四份独立公共参数估计，不合并跨艇似然。风险查询使用其g候选并集的保守外包，按四份归一化分布等权混合抽取一个g，并将此同一实例用于四艇；再分别抽取各艇个体参数。若某艇未支持该g，其个体条件候选退回共同物理先验，显式记录回退；不能凭插值制造支持，也不能为空时丢弃困难场景。S1用合法跨艇证据更新同一个g，并保留各艇条件响应。两者允许访问相同合法数据，差异在于是否实施共享更新。并混合测度不等于真实后验或严格最坏情形保证。

T0仅在辨识残差中使用当前命令，并将有效延迟/迟滞按0处理；候选池仍包含相同21维参数，真实执行器与风险前推仍使用完整模型。T1按候选传播命令队列及迟滞状态。B-off不得换成另一种ensemble、删去参数维度或改变异常样本规则。分析S、T主效应及交互，而非仅比较最强与最弱两组。

## 3. 防止混杂的附加消融

- Width-only：仅将Actor宽度输入固定为开发集预先冻结的常量；估计集合及风险查询集合完全不变。
- C-off：仅令低尾比例alpha=1，保留同样场景、Critic、熵项和更新预算；C属于继承的团队低尾机制。
- Memory-only：给无辨识/无共享参照相同长度、掩码与编码容量的合法历史输入，检验收益是否只是增加记忆。
- 点估计与固定集合主对照使用同一摘要维度和占位掩码，避免输入容量、网络大小或额外真值造成优势。

## 4. 先辨识、再闭环

先用各方法共用的合法离线轨迹与冻结名义控制探针，固定动作及观测，比较预测、覆盖和误归因。这一步隔离策略改变数据分布的影响，不作为任务性能胜出证据。再对各组分别从头训练闭环策略，比较总体效果；不能直接给同一权重换估计器后宣称最终算法优劣。

划分独立校准、开发、测试种子；校准残差界和宽度尺度，开发集选择配置与训练检查点，测试只执行冻结选择。建议至少5个独立训练种子，各方法使用配对场景种子；统计单位为训练种子，场景内配对，不把物理步当独立重复。

协议包括名义、回合固定、分段变化及单列有界漂移。变化时刻在预注册窗口随机抽取，各方法共用，不固定100步且不提供变化提示。共享变化与单艇故障分别测试，避免只测有利于共享的情况。参数范围、命令幅度与整数延迟上限先校准再冻结，不沿用旧CH4范围冒充实测域。

## 5. 指标、预算与可否证条件

分别报告逐维及21维联合覆盖、归一化宽度、有效支持量、空集/不一致率、回退率及回退后有效率。预测误差分流场、响应和时序因素；以延迟单变而g不变等受控场景检验流场误归因。闭环报告成功、碰撞、原奖励、配对名义损失和低回报尾部，以及保护干预和计算/显存/环境交互开销。

恢复定义为变化后误差连续w步低于冻结校准阈值；w及阈值在测试前确定，同时报告任务恢复。未恢复、碰撞终止与超时必须保留，给出截止时刻和删失比例；不能只算已恢复样本的均值。

候选预算M、场景数N、alpha与最低尾部支持k在开发阶段做预算敏感性分析后冻结；各组同预算，报告每步耗时。必须满足ceil(alpha*N)不低于预注册k；支持不足触发显式回退。有限场景的Critic低尾估计不能称严格最坏回报。

若共享在相同覆盖水平不能改善宽度/样本效率，或单艇故障造成其他艇集合错误收缩，A假设未获支持；若对齐不降低时序误归因或恢复时间，B假设未获支持；若收益仅来自更宽集合、更多记忆、保护器或额外预算，应收缩贡献。性能门槛及置信区间规则须测试前冻结，目前均未验收。

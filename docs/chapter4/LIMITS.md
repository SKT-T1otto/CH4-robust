# 当前边界、预算与未验收事项

当前交付是新 CH4 研究实现、运行合同和受限机制验证入口。原 SIRSA 复现、名义任务能力、A/B/C 的独立性能增益、正式鲁棒性、Linux 原生准入与论文创新性必须分别判断；任何检查通过都不自动更新 `performance_passed=false`。

## 必须保留的来源事实

本目录来自正在演化的 Active 工作树快照。`CH4_START_HERE.md`、`_snapshot/validation_report.json` 已记载 `path_option_identity` 与 pure-MARL 来源校验失败；新增 CH4 源码清单不会消除此事实。`core/` 与 `chapter3_bser/` 通过冻结父文件清单约束，原 provenance 不重新签署，旧模型和历史实验结果不改身份。是否适合作为最终第三章任务底座，仍需独立任务能力证据。

当前运行利用父环境公共接口与部分内部实例接入点，尚不等于稳定发布的插件 API。将来迁移第三章更新必须逐项审查、追加新 CH4 来源、重新原生验证，不能把 Active 整目录覆盖过来。旧 CH3/CH4/CH5 与 Active 的文件完整性证据由本次总验证报告给出。

## 估计与物理模型限制

这是简化三维平移模型，不是完整六自由度 AUV、水动力辨识或真实海况验证。原仿真单位未做实物校准，流场空间相位当前固定为零；新增未知相位、传感噪声或通信限制需要独立版本身份和验证。

有限粒子可能漏掉真值；速度残差经验容差、窗口和包络 padding 不构成严格集合包含定理。共享检验会受个体模型失配影响，盒状凸包忽略参数关联。流场垂向增量与个体浮力增量、噪声与响应参数可能难以辨识；不能将集合收缩直接解释为物理参数已唯一恢复。延迟/迟滞变化、裁剪或接触下，公开 eligibility 和重置也不保证总能识别变化原因。

ensemble 使用均值±标准差，未建立覆盖率校准。完整公开先验窗口估计是为避免递归塌缩的适配选择，并不是原 SIRSA 精确复现。全先验回退可能提高覆盖但降低实用性，须同时看宽度、有效率、重置与任务控制结果，不能只报告覆盖。

`heldout_flow` 与 `heldout_response` 故意使真实参数超出原公开先验；目前估计器不能表示该域全部真值。应报告漏覆盖、无效状态与失败，而不是借此声称超域校准或自动先验发现。两个域的边界与训练域部分相接，物理留出范围以配置逐项定义。

## 风险目标和消融限制

尾部量是声明采样测度下的有限个 Q 查询低值均值，不是集合最小值、真实回报 CVaR 的精确计算或最坏情况保证。支持门槛仅检查真实参数 context 的经验邻域，未约束状态动作联合分布；邻域通过后仍可能有 Critic 外推误差。支持不足时普通 SAC 回退可能占大多数更新，须报告支持/回退比例，不能仅因配置 `risk=true` 就宣称有效进行了尾部学习。

`c_off` 保持相同集合查询与支持门槛，仅将训练 `risk_alpha` 设为 1，检验平均集合价值与低尾偏好的差异；阶段输入由独立的 `phase_off` 消融。两者仍需独立重训和足够支持才有解释力。`b_off` 以共享监督 ensemble 替换物理历史集合，改变的内容多于单个时序项；`fixed_width` 同时改变宽度输入与风险查询集合；`point` 与区间参照的风险目标也不同。当前矩阵可作候选对照，但尚不足以自动得出每个 A/B/C 的净效应。传统扰动观测器/ESO、M2TD3、更强名义策略等 PDF 候选强对照尚未实现，不能声称已覆盖全部基线。

## 控制保护与安全限制

默认保护关闭。`finite_probe` 只针对公开几何证据、有限抽样参数、有限时域和有限未知执行器状态极值做探测。失败后输出受限制动或无可验证候选状态；回退本身也没有完整安全证明。未知障碍、错误集合、未覆盖噪声、过强扰动及物理控制能力不足仍可导致碰撞或超时。

原始奖励和成功/碰撞日志始终保留，较高回报不能覆盖失败事件；没有全局安全保证、递归可行性或真实海试保证。信息流是 Python API/字段级隔离，原始转移文件中仍含特权诊断，不是操作系统级权限隔离。

## 指标与恢复的限制

成功率给出 Wilson 区间，回报报告均值与低回报样本尾部，集合报告逐维/联合覆盖、宽度和有效率。阶段诊断及恢复要求窗口内阶段一致并满足运动误差、无碰撞和阶段推进/驻留/保持条件。它们是工程指标，不是任务可恢复性证明。

恢复只针对显式的非初始参数突变事件计时，窗口不能跨越下一参数变化；未恢复使用 `recovery_steps=null`、删失步数和 `next_change`/`episode_end` 原因。汇总报告 `recovery_event_count`、`recovery_unrecovered_rate` 和仅以已观察恢复为条件的 `recovery_mean_steps`；无事件时未恢复率为 `null`，无已恢复样本时条件均值为 `null`，不将删失量伪装成真实恢复时间。漂移协议没有逐步恢复事件定义。当前运动误差诊断用集合中心的一步名义响应，未重放完整候选延迟/迟滞；其阈值不等于真实跟踪稳定性界。

当前 `wall_seconds` 与每物理步耗时覆盖回合采集循环、其中的学习更新和逐步日志写入；不包括场景生成、runtime 初始化和回合后的检查点写入，不能当作完整作业端到端成本。规划/估计/保护/更新成本尚未完整分解；CPU/线程和平台差异需单独报告。恢复汇总区分承接物理步和本次实际物理步/更新数，承接历史耗时不是本次新增耗时。逐回合波动不是训练种子不确定性，汇总明确保留 `training_seed_uncertainty_established=false`。同场景名义差值只有检查点、场景、种子和域一致才成立。

## 下一阶段验收条件

先冻结公共任务与来源边界，在目标平台拿到当前 native validation receipt；另外完成原 SIRSA 轻量原设置的独立复现。随后确认名义任务能力，开发集校准集合/支持/恢复候选阈值，独立重训主组和消融，最后冻结测试矩阵并运行多种子比较。每一阶段都需保留失败运行和实际资源量。没有足够证据的参数范围、收益、原论文复现、再分发许可或性能主张保持 `REVIEW_REQUIRED`。

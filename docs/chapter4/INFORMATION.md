# 信息、动作与训练标签合同

CH4 延续父环境的可靠公共规划信息和四车辆任务合同。允许共享的公开状态不等于严格局部分散观测；本实现不声称严格分散执行，也不增加第五章通信丢包/延迟研究。Actor 运行入口 `MultiAgentSAC.act` 只接受 `PolicyInput(observations, active)`，不接收环境、info、真实参数或诊断对象。

## 61D 部署输入与 30D 真实 context

每车输入 `61D = 28 + 4 + 4 + 3 + 3 + 1 + 18`。四车输入张量形状是 `(4,61)`，活动掩码独立为 `(4,)`。

| 切片（零起点） | 维度 | 来源与含义 |
| --- | --- | --- |
| `[0:28]` | 28 | 父环境公开任务观测，保持原字段含义 |
| `[28:32]` | 4 | 车辆/角色 one-hot |
| `[32:36]` | 4 | search、standby、approach、hold 阶段 one-hot；`phase_off` 置零 |
| `[36:39]` | 3 | 上一步送往执行器的归一化命令 |
| `[39:42]` | 3 | 从允许位置/速度/导航目标与名义车辆规格计算的公开参考命令 |
| `[42:43]` | 1 | 当前步/本实验最大步数 |
| `[43:52]` | 9 | 当前每车参数集合中心，按公开先验跨度归一化 |
| `[52:61]` | 9 | 当前每车参数集合**全宽**/公开先验跨度 |

实现输入采用全宽，不是 PDF 第 9 页写的半宽；若对照公式或换后端必须保留这个因子 2 的差异。`point` 将宽度置零，`none` 将中心/宽度全置零，`fixed_width` 将宽度置一。阶段仅改变条件输入，不降低原捕获/保持条件；日志阶段由独立公开状态计算，`phase_off` 不会把真实阶段诊断一并清零。公开参考来自 OLD/D2 的名义控制运算，不是当前 B2 权重输出。

真实物理 context 独立为 `30D = 2 + 4×7`：前两项为所有车辆共享的流场幅度，后面依车辆顺序为各车阻力、浮力增量、能力、限速、迟滞、整数延迟、噪声。`PrivilegedContext.local` 用 `(4,9)` 表示并校验共享场一致；`joint(normalize(...))` 形成训练 Critic 的 30D 标签。不存在四套互相矛盾的“共享流场”。留出域真值可越出训练先验的归一化 [0,1]，不能为了看起来合规而裁剪真值。

## 公开历史与估计条件

`History` 保存长度默认 5 的 `(H,4,12)` 窗口，每个转移由 `position/20`、`velocity/3`、`sent_command`、`next_velocity/3` 构成，并附 `(H,4)` 有效掩码。缩放是实现中的固定特征尺度，不代表物理标定。粒子估计器另外维护公开命令队列和每个候选的推测迟滞状态。

部署估计器可用公开测得的位置、速度、公开活动/碰撞状态、已发命令、车辆名义规格和已声明先验。排除辨识样本依据保守公开条件：前后车辆活动、未到最低可能限速边缘、未到墙边、未碰撞。它不读模拟器真值裁剪标志、真实延迟队列、真实施加动作或真实参数。排除辨识不删除该回合任务失败或轨迹。

监督 ensemble 只在训练更新时用真实参数标签；评估推理固定网络权重，从完整公开先验和当前公开窗口计算启发式集合。无有效历史时保留先验，没有训练更新时显式标记无效先验。粒子集合不用真值标签在线收缩，空/不足支持会返回无效全先验并重置推测状态。

## 四类命令与实际加速度

Actor 的随机变量是高斯经 tanh 得到的每车 3D 绝对归一化命令。公开参考通过 `mean + atanh(reference)` 进入高斯均值；网络输出零均值增量时确定性动作接近参考，随后计算最终动作的精确对数密度。CH4 新环境实例关闭内部残差先验且残差尺度置一，避免二次叠加；父残差入口与源码不改。

| 字段 | 产生位置 | 是否可用于部署历史 |
| --- | --- | --- |
| `proposal` | Actor、暖机均匀探索或无学习名义参考的原始提案 | 是，策略已知自己的提案 |
| `sent_command` | 活动门控、裁剪与共同 `PublicProtection` 后，当前送往执行器 | 是；这是在线估计器使用的命令 |
| `delivered_command` | 真实整数延迟队列取出的历史命令 | 当前仅特权诊断，在线估计器自行推测 |
| `actuated_normalized` | 真实迟滞滤波、命令噪声、[-1,1] 裁剪后，送入原积分的量 | 当前仅特权诊断 |

另存 `actual_acceleration`，它是原物理环境记录的实际加速度结果，不应当作 Actor 所采样命令或额外传感输入。受扰后 `proposal != actual_acceleration` 不表示策略未执行；本回放不会沿用第三章 option 的等值筛选来丢弃正常受扰样本。可选保护替换命令则是策略外部确定的控制处理，单独记录 `guard` 和干预率。

物理路径为：当前命令入队 → 按每车整数延迟取命令 → 迟滞更新 → 噪声与归一化裁剪 → 乘有效能力尺度一次 → 原阻力/流场/浮力积分 → 原限速和位置/任务判定。非活动车辆沿用原冻结规则；名义协议走原积分快路径。

## 训练期特权隔离

| 数据 | 可读取模块 | 禁止解释 |
| --- | --- | --- |
| 61D 公开输入与活动掩码 | Actor、Critic、公开诊断 | 不是严格局部传感合同 |
| 公开历史、名义规格、估计集合 | 在线估计器、可选保护、Actor 的集合特征 | 不含真实执行器记忆 |
| 真实 `context`/事实 `next_context` | 训练 Critic、经验支持库、离线诊断 | 不直接给部署 Actor |
| `privileged_target` | 训练 ensemble 的监督损失 | 不作为评估在线输入 |
| `hidden_actuator`、真值和实际施加量 | 原始诊断日志/离线评分 | 不反馈给估计器或保护 |
| 完整真实障碍、未来目标与未送达信息 | 原环境内部判定 | 不作为新增策略旁路 |

原始 `transitions.jsonl` 将公开字段和明确命名的特权诊断写在同一条记录中，尚未拆成权限隔离的文件。这是运行 API 和字段用途的逻辑隔离，不能宣称已实现磁盘级访问控制；后续训练/可视化消费者须遵守同一白名单。Actor 接口不含特权字段，但这本身也不是形式化信息流证明。

Critic 回放保留原奖励、原终止/collector 截断、真实当前和下一 context、提案及公开前后集合/历史。当前转移先挂起，下一物理转移到来后才补事实 `next_context`；真正终止没有未来 bootstrap。尾部查询只用于 Actor 效用近似，不给同一事实奖励复制多种参数标签。`ContextSupport` 只在训练事实回放中积累，不拿开发/测试数据重新训练。

## 场景与评估边界

train/dev/test 使用独立场景种子块；场景噪声与参数扰动的随机流按场景身份固定。训练种子可由 `--seed` 覆盖，影响模型/回放随机性，不因此改变预定义场景种子块。`domain` 另外标识真实采样域，公开 `disturbance.bounds` 不随 heldout 改写。新地图与新参数是两种泛化轴；当前域划分提供可复核的参数留出协议，仍需足够独立训练与场景证据。

评估只加载匹配方法、网络/估计/风险/保护/恢复合同、原公开先验和当前源码身份的本地 CH4 检查点；训练种子、场景种子块、每回合时限、参考配置、训练总预算、域注册表、参数变化时刻和漂移速率同样保持与检查点一致。可以选择 dev/test、预定义 domain/protocol 和评估回合数，不能借评估把新的时限或额外信息权限混入同一身份。训练权重和场景身份写入结果；名义/受扰差值要求同检查点、同场景、同训练种子、同物理域。汇总通过比较合同哈希和实际检查点训练回合数拒绝不兼容运行，训练种子除外以支持跨种子统计。最终测试需显式确认和冻结标签，不能通过测试集回调 identifier 或选检查点。
